# 学习图像清单

后续整轮近景改造已接入，当前学习流程见[近景交付记录](memory-closeup-delivery.md)。下文保留原总览与上一轮改造记录。

本清单记录 34 张学习用图的入口、处理范围与记忆用途。依据是本轮逐图审视，以及对图片引用、热点位置、站点文案和学习组件的代码核对；未进行浏览器验收或冒烟测试。

考前聚焦的 30 张场景中，6 张采用局部补画，14 张是本轮补充资料新增的独立场景，10 张旧图保留稳定位置。新增场景中的“法典长河”另作六盏灯、四段石门的数量校正。原一般保证书房和 3 张案件背景继续保留。局部补画只强化承担记忆任务的物件与动作，不另换整条路线的地点。

前 30 张由 [scene-art.json](../src/features/focus/memory/scene-art.json) 注册，在 `#/focus/memory/:palaceId` 经 [MemoryScene.jsx](../src/features/focus/memory/MemoryScene.jsx) 展示。学习时将当前物件名、联想动作和关键区别放在图边；遮住讲解后，保留物件与问题供回忆，再展开核对。具体主体、数额、期间、门槛和例外仍以站点文字清单为准。
