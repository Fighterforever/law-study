# 记忆宫殿近景学习改造

## 本轮目标

让学习者站到规则发生的位置，看清谁在什么条件下做了什么。总览继续保存原路线，主要学习画面改为固定站位的单站近景。30 个主题、183 个站点均纳入，新增 183 帧站点近景和 30 帧同机位变式，共 213 个学习镜头；30 张旧总览保留。不改变原站点编号、原考点、客观题或备份格式。

## 画面制作

每个站点有独立近景：保留原场所的材质和相邻参照，镜头降到桌边、门口或柜台前。人物、手、文书与普通物件共同表达动作。减少需要另行解释的虚构机关，法定名称、期间、比例和例外用页面文字准确呈现。

每个主题选择一个既有变式，制作同机位的第二幅画面。改变一个关键事实，保留人物、朝向和相邻物件，让变化的法律后果容易比较。对照题仍依据原讲义单元与既有变式，不增加未经核对的规则。

图像以每主题一张分镜素材保存，网页每次只呈现其中一个完整镜头；不用整张分镜拼图作为学习画面。相邻帧边界只用于资产定位。生成素材存在不等高分镜，已按实际像素边界逐帧登记；页面保留各帧画幅，对照区域固定高度，切换时不跳动。每帧都有独立站点映射，原总览仍承担地点定位。素材表中的一个格子对应一个学习镜头，页面根据站点取出该帧；整张 atlas 只作为图片文件保存，不要求学习者在拼图里寻找考点。

## 学习流程

1. 进入考点关联站，默认显示近景。用总览查看当前位置，再回到近景。
2. 看物件和短动作，核对该站完整法律条件。
3. 遮住讲解，凭图回答；展开后补足遗漏。
4. 在同机位对照中只改一个事实，先判断再展开理由。此步骤不计掌握分数。
5. 关图进行原闭卷复述、口头变式与关联客观题。看过图、点击物件或展开理由不增加掌握程度。

## 页面与交互

- 近景、总览有明确分工。单站切换回到近景，保留同一地点的左右关系。
- 图文在桌面并列；小屏幕先图后文。切到下一站时回到该站画面，避免只看到了下方答案。
- 对照使用相同画框切换两幅图，原情境和改变的事实明确标注。换事实收起上一条解析。
- 遮讲解模式收起解码、动作和对照解析；闭卷只在用户主动求助后显示场景提示。
- 路线只保留一组站点导航。详细走法、来源与对应客观题按需展开。
- 保留键盘操作、清楚的焦点、减少动画设置和原备份能力。

## 固定视角的理由与镜头约束

总览帮助辨认各站关系，单站近景帮助看清材料交接和行为条件。每站选定一个可实际站立或坐下的位置：柜台外侧、案桌前或记录席。镜头采用眼平或略俯视桌面的角度，以当前动作能被看清为准；不统一强加一个俯角。

从总览进入近景时，保留场所的主要材质、相邻地标和已有左右关系。复习同一站沿用同一机位，不自动环绕，不为了更换画面而从另一侧重拍。同机位变式固定人物位置、物件位置与光线，只修改承担关键事实的文书或动作。抽象条件留给邻近文字，不能让装饰颜色、人物表情或物件数量暗示未经讲解的规则。

地面视角与俯瞰视角支持的空间任务有所不同；学习与测试之间改变视角、朝向也可能增加场景识别负担。因此，本项目将稳定总览和稳定近景分工使用。相关实验研究空间学习与导航，没有给出法考图片的最佳俯角，也没有证明写实照片或游戏美术一定更好。这里选用具有现实用途的物件和清楚动作，并保留用户熟悉的游戏式场所氛围。[Brunyé 等（2012）](https://doi.org/10.1016/j.chb.2011.09.008)、[Shelton 与 McNamara（2004）](https://pubmed.ncbi.nlm.nih.gov/14736304/)。

## 当前页主流程入口缩减

主题页围绕当前站组织学习，主要操作保持为“看图学习”和“闭卷练习”。近景默认展开，总览收在明确的辅助切换中；每页只留一组站点导航。站点正文按“眼前动作 → 法律条件 → 遮讲解回忆”排列，图和条件彼此邻近。

同机位变式随对应站出现，不另开一套并列课程或计分入口。详细走法、讲义来源、关联客观题和原四个案情任务按需进入，保留原内容及进度。顺序练习、随机抽问和薄弱复测归在闭卷方式选择中，避免与下一站、遮讲解、图像切换同时争夺主要操作位置。

## 实施与检查

先逐站写出镜头和变式的对应关系，再生成图像、查看实际帧数与内容。发现数量、朝向或动作错误时只修正相关素材。通过必要单元测试检查站点与帧的覆盖、变式关联和旧进度兼容，再生产构建并按原授权发布 GitHub Pages。不进行冒烟或浏览器验收。

原研究依据见[记忆场景优化计划](memory-visual-plan.md)。视角分工参考 [Brunyé 等（2012）](https://doi.org/10.1016/j.chb.2011.09.008) 和 [Shelton 与 McNamara（2004）](https://pubmed.ncbi.nlm.nih.gov/14736304/)。近景与总览的法考应用是本项目的教学设计，学习表现由隔日关图回忆和变式判断检验。
