# 记忆学习交付核对

本次范围以工作区《记忆学习任务重构方案》为依据：公司失权、保险辨析、两个“两年”与涉外条件组合采用对应知识结构的交互；保留其他主题的短路线与全部原考点。目标是通过案情预测、反馈和隔日闭卷帮助理解记忆。精美场景为这些操作提供稳定的场所线索。

## 已有实现与证据

- 公司案件：`company-quest.js` 与 `CompanyQuest.jsx` 实现宽限期选择、股权范围、并行后续线和即时/隔日题；对应单元测试覆盖不同合法路径与关键起算点。
- 保险对照：`insurance-quest.js` 与 `InsuranceQuest.jsx` 实现单一事实对照、自由组合、错误案情回看、即时题及独立隔日题组。旧记录在读取边界归入即时题，分数和选项保留。
- 保险时间线：`insurance-clocks.js` 与 `InsuranceClocks.jsx` 分别计算交费门槛、成立/复效期间与能力例外；各项后果独立核对，闭卷收起场景。
- 涉外推演：`jurisdiction-quest.js` 与 `JurisdictionQuest.jsx` 分别处理非方便法院和外国在先受理后的中止。测试检查每项必要条件、并列条件中的缺项、两条返回路径对应题组、保存和复测。
- 学习桌：`memory-agenda.js` 与 `MemoryDesk.jsx` 衔接四个任务的原进度，优先续题和复测；显示今日首次分数，最后两天不推荐新场景，考试日停止首页推荐。
- 原创图像在 `public/quests/`，生成记录在本目录各主题的 `*-art.md`。没有发布原 PDF、完整 OCR、真实案卷或机械三维陈列草稿。
- 原有短路线、纯文字题、备份与讲义页码入口继续保留。单元测试和生产构建仅证明逻辑与打包，不替代实际页面检查。

## 尚待实际页面核验

Mac 连续多轮锁屏，CUA 明确返回无法自动解锁。需要手动解锁后完成以下检查，才能判断视觉与操作交付是否成立：

1. 在桌面与约 390px 手机宽度查看新学习桌、保险时间线和涉外推演桌，检查文字对比、换行、滚动顺序与横向溢出；保留截图并据实际效果调整。
2. 从学习桌续作正在进行的闭卷题，确认路由进入正确题目；从隔日入口进入对应题组，确认题面、记录与返回流程一致。
3. 保险时间线选错起点后核对，检查法定期间的图示更新；改变交费年限和能力事实，检查界面撤回答案及新的反馈。
4. 涉外任务改变一项与多项事实，检查条件图的缺项提示、复盘和错误案情带回；查看手机上反馈是否容易找到。
5. 检查键盘操作、刷新续做及减少动态效果设置。已有单元测试不作为这些实际体验已完成的证据。

当前不能认定整体验收完成。下一步是实际页面核验与据此修正；不再用新增模块替代这一步。学习收益也不能从游玩时长或即时分数推断，应观察隔日无提示表现。
