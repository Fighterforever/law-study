## 考前聚焦

考前聚焦现含五份2026讲义，共111页：商经知36页、三国法15页、民诉16页，以及补充1理论法36页、补充2刑法8页。提供135个考点单元、214道原创客观题，提供30条记忆路线。全部考点可按学科、讲义和学习状态筛选，底部有每份PDF各自的逐页索引。已核实的旧背诵卷重合点列出原书双页码，其他关联按对应课程查阅。原PDF、扫描图及完整OCR不随网站发布。

直接打开[补充1·理论法](https://fighterforever.github.io/law-study/#/focus/library?paper=focus-theory-supplement-1)或[补充2·刑法](https://fighterforever.github.io/law-study/#/focus/library?paper=focus-criminal-supplement-2)。新增70个单元、104道原创题，沿用规则梳理、遮答复述、客观题辨析与隔日复测。优先专题并入9月7—9日的计划；到期复测先做，首轮仍按剩余预算安排，10—11日停止常规新增。旧考点及题目编号、答案顺序不变，原进度继续使用。内容范围和重点修正见[补充讲义说明](docs/focus-supplements.md)。

补充材料另有15幅原创记忆场景、100个位置。直接进入[补充1宫殿](https://fighterforever.github.io/law-study/#/focus/memory?paper=focus-theory-supplement-1)或[补充2宫殿](https://fighterforever.github.io/law-study/#/focus/memory?paper=focus-criminal-supplement-2)。全部70个补充单元都能定位相关场景；场景集中练易混条件，完整规则与客观题仍在原单元。目录可按科目、资料、关键词查找，今日推荐与原排课衔接。规则复述后须完成一道口头变式，再进入下一站；复盘可直接返回对应客观题。

本轮按[记忆场景优化计划](docs/memory-visual-plan.md)统一加强30幅图的物件定位、图旁联想动作和关键区别；引渡、外交、仲裁、WTO、执行与刑法检验台补画具体线索。新增“遮住讲解，凭图回忆”，先尝试再核对，随后关图做变式。每张图的处理结论见[34图清单](docs/memory-image-inventory.md)。场景学习计入原考点时间，保留已有学习记录。

记忆宫殿新增[公司失权案件任务](https://fighterforever.github.io/law-study/#/focus/memory/company-case)：起草催缴书、审查实际宽限期与决议主体、圈选未缴部分对应股权，再分别处理公司处置与股东救济。60日与90日宽限期、转让与相应减资注销均可选择。任务以三组事实变式及三道普通多选题收尾，次日提供另一组三道变式题；重复复测仍使用这组题。示范、首次判断、订正与闭卷结果分开记录，刷新续做及原v1备份均可使用。其他主题目前保留原有短路线。

原创事务所场景由内置imagegen生成，资产与完整提示词见[美术记录](docs/quest-art.md)。三维陈列草稿不作为当前学习入口，也不打包进网页。

[记忆主题目录](https://fighterforever.github.io/law-study/#/focus/memory)把场景与四个案件任务归入对应主题。优先续完闭卷题，再处理到期复测与本轮错点；原短路线的待续草稿和薄弱位置也会提示。直接闭卷复用原任务进度，不另存一份成绩。今日首次成绩保留，即时题与隔日变式分别记录；考前最后两天不再推荐新的长场景，考试日停止任务推荐，资料仍可自由查阅。

[保险对照任务](https://fighterforever.github.io/law-study/#/focus/memory/insurance-case)专练不如实告知的解除、拒赔和退费。六组双案卷每次改变一项事实，也可自由组合条件；先预测再展开结论，最后收起场景完成三道多选题。次日另有三道变式，交叉判断故意与重大过失、两道解除期间和保险费返还；以后再次复测仍使用该组变式。学习记录保留错误案情，可直接带回对照台重新判断。旧版原题成绩继续保留并归入即时题。原创场景与提示词见[保险美术记录](docs/insurance-art.md)。

[保险账本与时间线](https://fighterforever.github.io/law-study/#/focus/memory/insurance-clocks)把第43条的交费年限与第44条的成立、复效期间分开操作。点击交费凭证、移动事故位置，分别判断起点、保险金与现金价值；核对后只改一项事实再判断。完成三道即时闭卷题后，次日可做另一组三道变式题。受益人等其他保险考点仍在原单元学习。

[涉外案件推演桌](https://fighterforever.github.io/law-study/#/focus/memory/jurisdiction-case)分别审查非方便法院异议与外国先受理后的中止申请。点击案情可改变一项或多项事实；提交处理意见后展开必要条件，逐项指出阻碍，并区分“可以裁定”与“必须裁定”。即时闭卷与隔日变式各三题，判断有误的案情可带回重练。原创港城书院插画和完整提示词见[美术记录](docs/jurisdiction-art.md)。

1. 先选择复习起点。民诉比较熟悉，可用“程序法有基础”配置，每组先用约8分钟闭卷查漏；陌生科目先看讲解。
2. 按“今日冲刺”开始：规则梳理、闭卷复述、客观题逐项辨析。选项每轮随机排列，刷新后保留当前顺序和勾选。
3. 次日撤提示复测。错题、漏项和拿不准的规则优先回访；不同日期独立答对后逐步拉开间隔。
4. 记忆宫殿有30幅可点击、可放大的主题场景，覆盖183个固定位置。每站用一个动作串联条件，配有核对清单、易错区别和一道口头变式题。先沿路记忆，再关图乱序抽问；用过提示、漏项或变式混淆的位置进入薄弱点复测。当前题、回忆草稿、提示和勾选随时保存，刷新可续练。
5. 七日表默认安排9月5日至11日，9月12日考试。周末300分钟、工作日150分钟，可调整；10日、11日停止常规新增。两栏共用总预算，并保留其他科目与休息时间。未排入预算的考点可以自由查阅。

题目自动逐项核对，口头复述由自己对照要点评分。学习记录中的“首轮完成”和“隔日复测通过”分别显示。复述、宫殿和答题草稿均可导出备份。

## 八科原课程

保留61个教学单元、183道课堂题、16题民诉诊断池及16道综合复核题。每节课从法律关系和短案例讲起，分别检查结论与理由，再按错因补讲。

已补清一般保证、公司人格否认、劳务派遣、新仲裁法、执行救济等规则表达，并修正周末时间按钮、真实考期计算、跨午夜日期刷新和正文搜索。原课程地图可直接进入同科的聚焦考点。

## 来源与学习方法

资料依据2026众合背诵卷和五份考前聚焦讲义。聚焦讲义按111页逐页整理；原八册1666页的旧课按标注页面选编，未逐页审校。具体法源区别与讲义纠偏写在对应考点中。实际案件请查询现行法律与司法解释。

学习方法以闭卷提取、反馈与间隔复习为主，空间联想辅助易漏清单。研究依据包括 [Karpicke与Blunt（2011）](https://learninglab.psych.purdue.edu/downloads/2011/2011_Karpicke_Blunt_Science.pdf) 与 [Dresler等（2017）](https://pmc.ncbi.nlm.nih.gov/articles/PMC5439266/)。具体课时与间隔结合剩余时间、学科基础和作答情况安排。

## 分享和保存

直接分享网站链接，访客无需GitHub账户，也不需要VPS或常开电脑。本站没有账户、后台、外部大模型API或分析追踪。

- 进度只写入当前浏览器的 localStorage，不上传GitHub，也不自动跨设备同步。
- 换设备前在“学习设置与备份”导出，再在新设备导入。清缓存、无痕窗口结束或更换域名会影响本地记录。
- 学习备份请自行保管，勿提交公开仓库。仓库不含原PDF、扫描页、完整OCR、私有阅读笔记或真实案件。
- GitHub Pages作为托管服务可能记录通常的网站访问日志；国内访问体验取决于实际网络。

## 开发

使用Node.js 24或兼容版本：

```sh
npm ci
npm run dev
npm test
npm run build
```

- `src/data/focus.json`：聚焦考点、客观题、重合关系、记忆路线和排课顺序。
- `src/data/memory-guides.json`：183站的联想动作、条件清单和口头变式；`src/features/focus/memory/`：主题场景与学习流程；`src/lib/memory*.js`：记忆评分、复测队列和续练草稿。
- `src/features/focus/`：新栏目界面；`src/lib/focus.js`：复测与预算；`focus-state.js`：备份数据校验。
- `src/features/focus/memory/quest/`：案件任务与独立闭卷界面；`src/lib/company-quest.js`：程序条件、评分、续做与隔日变式。
- `src/data/lessons.json`：八科原课程；`diagnostic.json`、`checkpoints.json`：诊断与综合复核。
- `src/lib/study.js`：共用日期、存储和原课程排课。

应用版本以 `package.json` 为准。学习记录格式版本由 `STATE_VERSION` 管理，原v1备份可继续导入。必要单元测试检查评分、复测间隔、预算、真实考期、备份兼容和内容引用。GitHub Actions在main更新后运行单元测试并发布Pages。

发现内容问题可在[Issues](https://github.com/Fighterforever/law-study/issues)注明单元标题、具体选项和来源；请勿提交真实案卷或个人学习备份。
