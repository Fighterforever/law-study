# 法习

一个公开访问、进度保存在各自浏览器的中文法考核心复习工具。

**网站：[fighterforever.github.io/law-study](https://fighterforever.github.io/law-study/)**

八科61个教学单元、183道原创课堂题，另有16题民诉诊断池（部分复用课堂题）及16道综合复核保留题。课程从概念入口和示范开始，先确认结论再选择理由，随后按错因补讲、跨日复现。它不代表八册资料或考试范围的完整覆盖。

## 开始学习

1. 选择“八科从基础讲起”或“程序法有基础”，也可逐科设置。
2. 设置真实开始日期、考试日期和每天可用时间。工作日支持120、150、180分钟；周末可调整。
3. 从“今日学习”开始，先复习到期规则，再学时间内能完成的小批新课。
4. 临近考试用“综合复核”检查已经学过的规则；最后两天停止常规新课，考试当天不排任务。保留题按剩余预算分组，未完成的组可继续。
5. 每隔几天到“学习设置与备份”导出记录。换设备时手动导入。

“熟悉”只是自述，不会被算为掌握。初步稳固要求完成教学、两个不同日期无提示通过、结论与理由均正确、通过变化情境，并处理课堂题及保留题的未复核错误。提示、猜测和当天看过反馈再答对都不制造新的独立成功日。没有实时AI阅卷或效果保证。

81个一级领域逐项区分已制作部分课程、计划内待补及后续扩展；每科详细缺口见网站“课程地图”和“内容与来源”。课程库大于两周自动选择量；没有被排入的单元仍可选学，不能据网站进度推断全科完成。

民诉诊断只定位具体题目，单课诊断仅折叠所有关联题均通过的段落，不完成整课。两次没有思路时先回讲解，之后可继续未测题。

网页保留作答中的结论、理由阶段、提示使用和选项顺序，刷新后继续。旧版仅凭诊断标记完成的课会回到学习中；检测规则改变时使用新的题目ID并重新安排，历史答案仍保留。

记忆宫殿是一个可选的四位置小试点：一般保证先诉抗辩权的例外。支持隐藏文字、隐藏整图、顺序与乱序回忆，回答由自己核对，不计为客观掌握。

## 隐私

- 无账户、后台、第三方分析追踪或外部大模型API。
- 学习记录仅写入当前浏览器的 localStorage，不上传GitHub，不会自动跨设备同步。
- 导出的JSON包含个人学习记录，应自行保管，不要提交到公开仓库。
- 本仓库不包含原PDF、扫描页、OCR、私有阅读笔记、工作单位或真实案件。
- GitHub Pages作为托管服务可能记录通常的网站访问日志；本站不额外收集访问者数据。

## 开发

需要Node.js 24或兼容版本。

```sh
npm ci
npm run dev
npm test
npm run build
```

React、Vite和依赖版本由 `package.json` 与锁文件管理。应用版本以 `package.json` 为准；学习记录格式版本由 `src/lib/study.js` 中 `STATE_VERSION` 定义，存储键保持稳定。

结构：`src/data/lessons.json` 是课堂内容；`diagnostic.json` 与 `checkpoints.json` 是诊断及保留题；`coverage.json` 是领域到课程的映射。`src/lib/study.js` 管理日期、记录与排课，`assessments.js` 管理综合复核，`learning.js` 处理补讲与当前题目证据。`src/App.jsx` 是界面。

必要单元测试覆盖评分、间隔、诊断减免、旧备份、作答草稿、真实考期及时间预算。完整开发核对记录见 [PLAN_REVIEW.md](PLAN_REVIEW.md)。

GitHub Actions在main更新后运行必要单元测试并发布Pages。不需要API密钥。题目ID保持稳定，撤下的单元不进入新复习队列，既有历史记录保留。内容修订应保留出处并核验会改变答案的条件，不通过批量生成数量代替内容质量。

## 分享与托管

直接分享上方公开网址即可，访客无需GitHub账户。进度按浏览器隔离，换设备前导出备份；清缓存、无痕窗口结束或更换域名都会影响本地记录的可访问性。

当前是静态网页，不需要VPS或常开电脑。GitHub保存源码并自动发布；如果以后迁移域名或另设主站，先导出进度再到新站导入。国内访问体验须用目标读者的实际网络检查，不能仅按服务器所在地保证速度。
